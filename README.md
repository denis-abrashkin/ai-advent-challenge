# AI Advent Challenge #8

## О челлендже

AI Advent Challenge — это 7-недельный интенсив по практической AI-разработке. Каждый будний день выдаётся новое задание. Цель — не просто писать код, а научиться эффективно использовать AI-инструменты (Claude Code, Codex, Cursor, OpenCode и др.) для решения реальных задач.

## Правила

| Параметр | Правило |
|---|---|
| Длительность | 7 недель |
| Заданий в неделю | 5 (пн–пт) |
| Время выдачи | 14:00 |
| Выходные | Суббота, воскресенье |
| Дедлайн | Все 5 заданий закрыты к следующему понедельнику 14:00 |
| Допуск | Максимум 15 минут |
| Сдача | Видео + код |

**Кто не закрыл все 5 заданий за неделю — выбывает.**

## Формат сдачи

1. Записать **видео** с демонстрацией работающего результата
2. Загрузить **код** (GitHub, Яндекс.Диск и т.д.)
3. Внести ссылки в таблицу
4. Убедиться, что видео открывается

## Главная стратегия

- **Максимально делегировать код AI-инструментам** — не писать всё вручную
- **Видео важнее кода** — демонстрация работающего результата решает всё
- **Не откладывать всё на выходные** — пятничные задания часто самые сложные
- **Использовать сильные модели для harness-разработки** (Claude, Opus)
- **Для API внутри приложений брать дешёвые модели** (DeepSeek и аналоги)
- **Делиться опытом в чате** — кооперативная среда, не соревнование

## Инструменты

- **Основной harness**: Claude Code
- **Рекомендуется попробовать**: Codex, Cursor, OpenCode
- **Плагины**: Caveman, AST Index
- **Языки и стеки**: любые (ограничений нет)
